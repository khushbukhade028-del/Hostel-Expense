# Project Statement

## Problem Statement

Students living in hostels often spend money on food, travel, stationery, shopping and other daily needs. It can become difficult to remember all the expenses and know how much money has been spent.

The Hostel Expense Tracker is made to help students record their daily expenses and check their total spending easily.

## Scope of the Project

The project focuses on basic expense management for hostel students.

It allows the user to:
- Add a new expense
- View the recorded expenses
- Calculate the total amount spent
- Exit the program

The project is designed as a simple Python-based application and does not require an online account or database.

## Target Users

The main users of this project are:
- College students living in hostels
- Students who want to keep track of their daily expenses
- Students who want a simple way to calculate their total spending

## High-Level Features

- Add expense details
- Store expense information while the program is running
- View recorded expenses
- Calculate total expenses
- Simple menu-based interface
- Easy to use for beginners
