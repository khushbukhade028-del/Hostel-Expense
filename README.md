#HOSTEL-EXPENSE-TRACKER


A simple, practical and database-powered expense management system built for hostel life.**

Managing hostel expenses can get messy — food, travel, laundry, stationery, subscriptions and those random “₹50 kaha gaye?” moments. 😭

**Hostel Expense Tracker** is a Python-based application that helps students record, view, update, delete and analyse their expenses in one place.

---

## ✨ What Does It Do?

| Option | Feature |
|---|---|
| ➕ | Add a new expense |
| 👀 | View saved expenses |
| 🧮 | Calculate total expenses |
| ✏️ | Update an existing expense |
| 🗑️ | Delete an expense |
| 🚪 | Exit the application |

---

## 🚀 Key Features

### 💸 Expense Management
Record important details for every expense:
- 📅 Date
- 🏷️ Category
- 💰 Amount
- 📝 Description

### 🗄️ SQLite Database
Expense records are stored using **SQLite**, allowing data to persist instead of depending only on a temporary Python list.

### ✏️ Update & Delete
Users can select an expense using its ID and update or delete the record.

### 🧮 Automatic Total
The application calculates the total amount spent from stored expenses.
